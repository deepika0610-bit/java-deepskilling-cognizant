Introduction to React
Single Page Applications (SPA)

JSX (JavaScript XML)

Props

To understand the fundamentals of React by developing dynamic and interactive Single Page Applications (SPAs) using JSX, components, React Hooks, event handling, conditional rendering, props, and list rendering while following React's component-based architecture.
