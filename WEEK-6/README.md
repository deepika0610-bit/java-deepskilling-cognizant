# Git Hands-on 1

## Objective

This hands-on introduces the fundamentals of Git and GitLab. It covers Git installation, configuration, repository creation, tracking files, committing changes, and connecting a local repository to a remote GitLab repository.

## Topics Covered

- Installing Git
- Configuring Git user details
- Setting Notepad++ as the default Git editor
- Creating Git aliases
- Creating a local Git repository
- Understanding the Working Directory
- Understanding the Staging Area
- Tracking files using Git
- Creating commits
- Creating a remote repository in GitLab
- Connecting local and remote repositories
- Pushing code to GitLab
